## Decisions recorded in this plan

- **No disk cache for generator and judge either:** RESEARCH allowed the default cache for the generator (book text), but PATTERNS' shared pattern and `rag/experiments/about.py` pass `cache_dir=None` for every model, and an uncached run keeps every `get_llm` call in the module checkable by one grep. Cost: a rerun regenerates answers. Rated reversible.
- **Answers run on repeat 1 only**; repeats re-draw only the `on` arm (the other arms are deterministic).
- **Gate positives** are `GoldConversation.expects_rewrite` (pronoun, constraint and clarify items), so topic-switch and standalone items are negatives (RESEARCH A8).
- **(e) counts** the first rewriter call of each item where the gate fired, answer and clarify items, repeat 1; the second `allow_clarify=False` call of a clarify item is not counted (the committed rule's wording).
- **Committed text excludes model output:** `render_results` shows counts, rates, reason codes and ids, never the rewritten, rejected or clarifying text, which stays in the gitignored `report.json` (RESEARCH Security Domain).
- **Rewriter-choice default reason** is the literal "qwen by default, not compared" when the only spec contains `qwen`, matching the committed rule.
