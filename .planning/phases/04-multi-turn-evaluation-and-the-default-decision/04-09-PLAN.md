## Phase Goal

**As a** system owner, **I want to** measure rewriting on and off against a multi-turn golden set, **so that** rewriting becomes the default only when it shows a gain outside the noise band and the numbers are recorded either way.

<objective>
Apply the recorded decision (D-13): add `test_the_default_matches_the_recorded_decision` and `test_the_results_file_records_every_decision` (Task 1) and `test_the_rewriter_default_matches_the_recorded_choice` (Task 2, D-10), and change a default only where the committed Results require it: the `RAG_REWRITE` default (only on "ships on"), the `RAG_REWRITER` default (only when another rewriter was chosen, D-10) and the answer-prompt question slot (only when the original-message slot measurably won, D-11). Each change lands in its own commit together with the Phase 3 test it overturns.

Purpose: ROADMAP criterion 4 ("the rewrite switch's default follows the rule"). The expected decision is "ships off (provisional: items pending human review)", in which case this plan changes no production code and the new test pins that the default and the recorded decision agree.

Output: two new tests in Task 1's commit and one in Task 2's commit (each of those commits carries a default change only when the Results require it), plus a Task 3 commit only when the question slot changes.
</objective>
