## Phase Goal

**As a** system owner, **I want to** measure rewriting on and off against a multi-turn golden set, **so that** rewriting becomes the default only when it shows a gain outside the noise band and the numbers are recorded either way.

<objective>
Apply the recorded decision (D-13): add `test_the_default_matches_the_recorded_decision` and `test_the_results_file_records_every_decision`, and change a default only where the committed Results require it: the `RAG_REWRITE` default (only on "ships on"), the `RAG_REWRITER` default (only when another rewriter was chosen, D-10) and the answer-prompt question slot (only when the original-message slot measurably won, D-11). Each change lands in its own commit together with the Phase 3 test it overturns.

Purpose: ROADMAP criterion 4 ("the rewrite switch's default follows the rule"). The expected decision is "ships off (provisional: items pending human review)", in which case this plan changes no production code and the new test pins that the default and the recorded decision agree.

Output: two new tests in one commit, plus zero to three conditional commits.
</objective>

## Why one plan touches rag/api and tests

The orchestrator splits plans by module, but it also requires that a default flip "must update Phase 3's test_build_default_service_ships_the_switch_off in the same commit". A flip without the test update leaves the suite red between commits, so each conditional change and the test it overturns share one task and one commit. ## Decisions recorded in this plan

- **Flip shape (only if ships on):** `setting("RAG_REWRITE", "1") == "1"`, so unset and `"1"` are on and `"0"` (or anything else) is off; the opposite of Phase 3's `setting("RAG_REWRITE", "") == "1"`. Rated costly: every deployment without the variable changes behaviour.
- **Slot change (only if measured):** the answer prompt receives a deep copy of the retrieval trace whose `question` is the original message; `Trace.question` and `trace.config["conversation"]` keep both texts as Phase 3 records them. Rated reversible (one call site).
