## Fixture design (shared by all tasks)

- Pipeline: `RetrievalPipeline.from_chunkset(chunkset, VectorIndex.build(chunkset.chunks, embedder), embedder, None)` with `embedder = HashingEmbedder()` and `chunkset = RecursiveChunker(size=40, overlap=5).chunk(Document.from_pages(PAGES))` (copy of `tests/test_retrieval.py` lines 105-119); config `CONFIGS["weighted"]`.
- `p1` (pronoun_follow_up): turn "What does a write ahead log record?" / "It records every change before it reaches the tree page."; message "Why is that needed?"; standalone "Why does a write ahead log record every change before the tree page?"; pages `[[2, 2]]`; evidence `["write ahead log"]`; one key fact.
- `s1` (standalone_in_conversation): turn about cats in the garden; message = standalone "What do stream processors join an event stream with?"; pages `[[3, 3]]`; evidence `["stream processors"]`.
- `a1` (ambiguous_follow_up, clarify): turns naming "write ahead log" and "event stream"; message "Which one is it?"; `must_contain` both terms.
- Scripted rewriter replies are lower case and use only words from the turns, so the Phase 3 guards accept them: `REWRITE: why does a write ahead log record every change before it reaches the tree page?` for `p1`, `STANDALONE` for `s1`, `CLARIFY: do you mean the write ahead log or the event stream?` for `a1`.
