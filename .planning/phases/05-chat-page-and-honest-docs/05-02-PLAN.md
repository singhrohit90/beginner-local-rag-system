## Harness contract (both files follow it)

- Command: `node tests/page_harness.js <scenario> '<json of SERVER_STRINGS>'` with the page's script text on stdin (from `re.search(r"<script>(.*)</script>", page, re.S).group(1)`, the syntax test's pattern). Output: exactly one JSON line on stdout. Exit code 0 whenever a JSON line was printed; scenario failures are `"ok": false` with the error message so Python shows it.
- Ids: `A_ID = "a" * 32`, `B_ID = "b" * 32`, `C_ID = "c" * 32`, `D_ID = "d" * 32` (the harness uses the same values).
- Documents served by the stub: `d1` named `a.pdf` and `d2` named `b.pdf`, both `state: "ready"`, `chunks: 3`, `chunker: "recursive"`, `flagged_chunks: 0`, `error: null`, `stage: null`; DELETE `/v1/documents/<id>` removes the document and answers 204.
- `/v1/health` answers `{"ready": true, "error": null}`; `/v1/status` answers `{"models_loaded": true, "llm": {"ok": true, "name": "fake", "detail": "ok"}, "search": {"ok": true, "detail": "ok"}, "error": null}`.
- `/v1/ask/stream` takes the next reply from the scenario's queue: `{"status": 404|409, "json": {"detail": ...}}` (an HTTP error before any byte), `{"final": {...}}` (status 200, one frame `event: final` plus `data: <json>` and a blank line, encoded with `TextEncoder`), or `{"hold": true}` (status 200, a `ReadableStream` whose controller the harness keeps to deliver later). An empty queue throws.
- `finalEvent(id, extra)` returns a complete final object: `answer` "Copies live on several nodes [S1].", `citations` ["S1"], `passages` [], `stages` [], `blocked` [], `skipped_by_scanner` [], `documents` [{"id": "d1", "name": "a.pdf"}], `abstained` false, `replace` false, `llm` "fake", `seconds` 0.1, `query_id` "q-<counter>", `conversation_id` id, `turn` 1, `kind` "answer", `rewrite` {"status": "off", "reason": null, "rewritten_question": null}, then `extra` merged over it.
- Every fetch call is recorded as `{url, method, body}` with `body` parsed from JSON when it is a string, plus its `signal`; `observe(ctx)` returns `conversationId` (read with `vm.runInContext("conversationId", ctx)`), `askBodies` (bodies of `/v1/ask/stream` calls in order), `askAborted` (each one's `signal.aborted`), `logText`, `errorText`, `detailText` (`textOf` of `#log`, `#error`, `#detail`), `logTags` (every element tag name under `#log`), `sendDisabled`.
- Context globals: `document`, the stub `fetch`, `setTimeout` returning 0 and `clearTimeout` doing nothing (the page's polls never fire), `Response`, `TextDecoder`, `TextEncoder`, `AbortController`, `ReadableStream`, a `FormData` class with `append`, `console`. Nothing else, so no real network is reachable.
- `boot` runs the script with `vm.runInContext` and waits until `vm.runInContext("ready && docs.length === 2", ctx)` is true. `ask(ctx, question)` sets `#question`'s value and awaits `#ask`'s `onsubmit({ preventDefault() {} })`. `waitFor(cond, label)` polls with `await new Promise((r) => setImmediate(r))` and throws `timeout: <label>` after 30 seconds of wall time.
