- `render_block` shows `turn.question` (the message as typed), not `turn.rewritten`; Phase 3/4 decide what the answer prompt's question slot holds.
- Plan-time probe (scratchpad, not committed): with this design 7 of the 10 `POISONED_DOCS` are defanged and re-scan clean, and P04, P07, P08 (written to evade the scanner) pass through unchanged apart from whitespace. That is the scanner's known limit (CLAUDE.md: one layer, not the only one).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored turn text -> next prompt | earlier questions come from the user and earlier answers may quote a poisoned document; both are untrusted when they come back (PRMT-03) |
| history block -> model | the block sits outside the passage tags, so its header and neutralization are its defence |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-10 | Tampering | stored-turn prompt injection reaching a later prompt | high | mitigate | `neutralize`: span replacement with `RULES[name].sub`, re-scan, withhold if still flagged; header labels turns as quoted text, not instructions |
| T-01-11 | Spoofing | role-line forgery (`User:` / `Assistant:` inside a stored answer) | medium | mitigate | `text.split()` collapses all whitespace, so each turn is exactly one line; tracer verify asserts a forged newline becomes inline text |
| T-01-12 | Tampering | stale `[S n]` markers colliding with the new passage numbering | medium | mitigate | `_CITATION.sub("", text)` with the single repo pattern |
| T-01-13 | Information disclosure | canary, system-prompt echo, external image or link in history | high | mitigate | `filter_output(text, "")` withholds the text; the guard's BLOCKED notice maps to `HISTORY_WITHHELD` |
| T-01-14 | Denial of service | history block overflowing the context window | medium | mitigate | `render_block` drops oldest turns to stay within `HISTORY_BLOCK_MAX_WORDS`; budget constants and `MODEL_CONTEXT_TOKENS` feed the worst-case test in 01-06; the hard per-conversation cap is Phase 2 (PRMT-04) |
| T-01-15 | Tampering | scanner bypass (P04, P07, P08 evade the rules) | medium | accept | one layer only, stated in the docstring and pinned as a known-limit test in 01-06 (CLAUDE.md: the output filter is a pattern list review has bypassed) |
| T-01-SC | Tampering | npm/pip/cargo installs | low | accept | no package is installed in this plan |
