## Phase Goal

**As a** system owner, **I want to** pin single-turn prompts and retrieval numbers with a committed snapshot test and recorded invariants before any shared function is edited, **so that** every later change can prove a plain question still produces the same prompt bytes, the same hit@5 0.865 and the same mrr 0.663.

<objective>
Pin the exact bytes of every single-turn prompt the code builds today, on the unedited code, in a commit of its own (D-04), and record the first retrieval-invariant run (D-15).

Purpose: this is the one-way door of the phase. The snapshot proves PRMT-02 ("with no history the produced prompt is byte-identical to today's"); it only proves it if it is taken before `rag/query/prompt.py`, `rag/query/generate.py`, `rag/security/defenses.py` or `rag/query/pipeline.py` changes. Plans 01-03 and 01-04 depend on this plan for that reason.

Output: `tests/test_prompt_snapshot.py` (24 case tests per D-01, the golden digest test per D-02, a fixture-directory test), 24 case files plus one digest manifest under `tests/snapshots/prompts/`, one commit holding only those files, and the first retrieval-invariant output pasted into the SUMMARY.
</objective>

## Choices made in this plan (Claude's discretion, recorded)

- Fixture passages: `SINGLE_PAGE_HIT` is PDF page 181 with a blank line and a `[S9]`-looking token inside its text (pins whitespace and marker handling); `PAGE_RANGE_HIT` is PDF pages 203-204. `QUESTION` is "How does a follower catch up after it falls behind the leader?".
- File format: system prompt, then `DELIMITER`, then user prompt, exact bytes, no trailing newline. The delimiter is a dashed line with no angle brackets so it can never collide with spotlight passage tags.
- The digest manifest stores digests only, not question text: attack questions in the golden set carry injection payloads, and the text is already in `data/golden/ddia_questions.jsonl` under the same id.
- The scratchpad generator imports `CASES`, `render_case`, `snapshot_text` and `golden_digests` from the committed test module, so the cases are defined once.

- `core.autocrlf` is `true` on this machine and there is no `.gitattributes`: fixtures are written as bytes with LF and read with `read_text(encoding="utf-8")` (universal newlines), so a CRLF checkout still compares equal.
